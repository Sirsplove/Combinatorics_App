Learn combinatorics

Most counting problems collapse to two questions. Answer them, then open a short lesson.

Which formula?

Does the order of items matter?

Can the same item be used more than once?

Answer both questions to see the formula.

Permutation

P(n,r) = n! / (n−r)!

Race finish order, passwords, seating. Sequence is the answer.

Combination

C(n,r) = n! / (r!(n−r)!)

Committees, pizza toppings, lottery tickets. The set is the answer.

Getting Started

  • Start with the Learn section to understand the basics

Navigation Tips

  • Click navigation links to switch between sections

  • Hover over navigation items for quick descriptions
  • All features work on mobile devices too!

Game Tips

  • Permutation Puzzle: Click two items to swap them
  • Combination Challenge: Select items that sum to the target
  • Probability Roulette: Enter probabilities as decimals (0.5 for 50%)
  • Graph Traversal: Click connected nodes to build your path
