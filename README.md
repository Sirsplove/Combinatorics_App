# Combinatorics App 🧮

A comprehensive web application that teaches combinatorics through real-world problem solving and engaging interactive games. Master combinatorial thinking while solving practical problems and playing fun puzzles!

## Features

### 🎯 Real-World Problem Solving
- **Scheduling Optimization**: Solve class scheduling conflicts using graph coloring
- **Route Optimization**: Find optimal delivery routes using the Traveling Salesman Problem
- **Password Security Analysis**: Calculate password possibilities under different security policies
- **Risk Assessment**: Analyze investment portfolio probabilities and expected returns

### 🎮 Interactive Games
- **Permutation Puzzle**: Arrange items in different orders to discover patterns
- **Combination Challenge**: Select the right combination of items to solve puzzles
- **Probability Roulette**: Predict outcomes and calculate probabilities in real-time
- **Graph Traversal**: Navigate networks and find optimal paths

### 🧮 Visual Calculator
- **Permutations (nPr)**: Calculate arrangements where order matters
- **Combinations (nCr)**: Calculate selections where order doesn't matter
- **Factorials (n!)**: Calculate the number of ways to arrange n objects
- **Subsets**: Calculate the total number of possible subsets
- **Step-by-step solutions** with detailed explanations

### 📚 Educational Content
- **Fundamentals**: Basic principles of counting, permutations, and combinations
- **Advanced Topics**: Generating functions, recurrence relations, and graph theory
- **Applications**: Real-world uses in computer science, biology, and economics

## Getting Started

1. **Open the App**: Simply open `index.html` in your web browser
2. **Navigate**: Use the top navigation to explore different sections
3. **Start Learning**: Begin with the "Learn" section to understand the fundamentals
4. **Practice**: Try the "Real Problems" section to solve practical scenarios
5. **Play Games**: Challenge yourself with interactive combinatorics games
6. **Use Calculator**: Calculate permutations, combinations, and more with step-by-step solutions

## How to Use

### Real-World Problems
1. Click on any problem category (Scheduling, Route Optimization, etc.)
2. Read the scenario and constraints
3. Follow the step-by-step solution approach
4. Try the interactive demo to see the concepts in action

### Games
1. Choose a game from the Games section
2. Read the instructions carefully
3. Use your combinatorial thinking to solve the puzzles
4. Track your score and try to improve!

### Calculator
1. Select the calculation type (Permutation, Combination, etc.)
2. Enter your values for n and r (if applicable)
3. See the result and detailed step-by-step solution
4. Experiment with different values to understand the patterns

### Learning Modules
1. Start with "Fundamentals" to learn the basics
2. Move to "Advanced Topics" for deeper understanding
3. Explore "Applications" to see real-world relevance
